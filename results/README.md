# Aggregate results

Generated by the executed analysis notebook. No campaign-level records or predictions are included.

- `model_comparison.csv`: historical random-test metrics; each row names its input set where relevant.
- `cross_validation.csv`: candidate selection scores on five common training folds.
- `input_algorithm_comparison.csv`: matched learner/input-set comparisons.
- `calibration.csv`: predicted versus observed probabilities in ten test-sample bins.
- `feature_ablation.csv`: CV scores after removing one input family.
- `risk_deciles.csv`: observed failure rate by predicted-risk decile.
- `review_capacity.csv`: hypothetical historical review selections, not measured coaching effects.
- `bootstrap.csv`: paired test-sample uncertainty with fitted predictions fixed.
- `category_performance.csv`: within-category historical test scores.
- `run_summary.json`: sample sizes, headline and temporal metrics, input checksum and software versions.

Read `../reports/methodology.md` before interpreting the scores as generalization estimates or decision benefits.
